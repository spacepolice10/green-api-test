# green-api-test

Клиент GREEN-API. Зависимости ставятся один раз:

```bash
npm install
```

## Локально

Запросы идут в настоящий API.

```bash
npm run dev
```

Откройте адрес из терминала, обычно http://localhost:5173. На экране входа укажите `idInstance` и `apiTokenInstance` из [кабинета GREEN-API](https://console.green-api.com/). Пара сохраняется только в этом браузере. С «Запомнить меня» она остаётся после закрытия вкладки, иначе — только в текущей сессии.

## С моками

MSW перехватывает запросы к GREEN-API, наружу ничего не уходит.

```bash
npm run dev:mock
```

Адрес тот же. На входе подойдёт любая непустая пара, например `idInstance` `1101123456` и любой токен. В списке уже есть Анна, Борис, группа и Марина. Ответ на отправленное сообщение приходит входящим примерно через полсекунды.
